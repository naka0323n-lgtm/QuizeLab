# QuizeLab for Windows

Windows 10 / 11 (64-bit) 向けのインストール不要版です。

[ダウンロード](https://github.com/naka0323n-lgtm/QuizeLab/raw/refs/heads/downloads/windows-v1.0.0/QuizeLab-Portable-1.0.0-x64.exe)

ダウンロードした exe をダブルクリックして起動します。Node.js は不要です。
問題と学習履歴は %APPDATA%\QuizeLab に保存されます。

コード署名なし。Windows 実機では未検証です。

# QuizeLab

カテゴリと問題集を作り、自分で登録した選択問題を繰り返し学べる Windows 向けローカルアプリです。問題と学習記録は SQLite に保存し、インターネット接続なしで利用できます。

## Windows で使う

[QuizeLab 1.3.0 インストール不要版をダウンロード](https://github.com/naka0323n-lgtm/QuizeLab/raw/refs/heads/downloads/windows-v1.3.0/QuizeLab-Portable-1.3.0-x64.exe)

Windows 10 / 11（64ビット）向けです。ダウンロードした `.exe` をダブルクリックして起動してください。Node.js やデータベースサーバーの準備は不要です。ウィンドウを閉じると内部サーバーも終了します。

コード署名されていないため、Windows SmartScreen が確認を表示する場合があります。配布元とファイルを確認してから実行してください。Windows 実機での動作は未検証です。

## いちばん簡単な共有方法

アカウントや共有サーバーの用意は不要です。問題集を **1つの `.quizelab` ファイル** にまとめて渡します。

**渡す人**

1. 共有したい問題集を開き、上部の「共有」を押します。
2. 「共有用ファイルを保存」を押して、保存場所を選びます。Windows アプリでは保存ダイアログが開きます。
3. 保存した `.quizelab` ファイルを、LINE・メール・USB・普段使っているファイル共有サービスなどで相手へ渡します。アプリが自動で送信・アップロードすることはありません。

**受け取る人**

1. QuizeLab **1.3.0 以降**を起動します。まだ持っていない場合は、上記のアプリのダウンロードリンクも相手に渡してください。
2. 右側の「問題集を読み込む」から、受け取った `.quizelab` ファイルを選びます。ファイルをアプリの画面にドラッグしても読み込めます。
3. 問題数・画像数を確認し、必要なら名前や保存先カテゴリを変更して「問題集を追加する」を押します。

問題文・選択肢・正解・解説・タグ・添付画像・習得ルールをまとめて共有します。習得済みの問題も含む、その問題集の全問題が対象です。画像の元ファイルを別途送る必要はありません。正解も含む編集可能な問題集なので、答えを隠した配布用の試験ファイルではありません。

学習履歴や回答・正解回数は含めません。受け取った人は0回から学習を開始します。取り込みは新しい問題集として行い、同じ名前があれば「(2)」などの番号を付けます。既存の問題集は上書きしません。キャンセル時やファイル検証エラー時には追加しません。

共有ファイルは **1問題集・2000問・50MBまで**です。画像が多くて超える場合は、画像を小さくするか問題集を分けてください。送信サービス側にも容量制限があります。受け取ったコピーを編集しても、渡した人の問題集には自動反映しません。更新版を共有する場合は、再度保存したファイルを渡してください。

## 問題に画像を添付する

「問題を追加」または「問題を編集」の「問題の画像」で画像ファイルを選び、プレビューを確認して保存します。1問につき1枚、PNG・JPEG・WebP、5MB以下に対応します（縦横10000px以下・2500万画素以下）。画像は受験画面と採点後の解説画面に表示され、クリックすると拡大できます。「画像を外す」で添付を削除できます。

画像は元ファイルへのリンクではなく SQLite に保存します。元の画像を移動・削除しても表示され、DB のバックアップに画像も含まれます。問題の画像を変更・除去すると、問題内容の変更としてその問題の学習カウントをリセットします。過去の採点記録が参照する画像は保持します。

旧版データの画像対応への移行前には `quizelab.sqlite.before-images.bak` を作成し、問題・タグ・学習回数を維持します。旧版を完全に終了してから新版を開いてください。

## カテゴリ → 問題集 → 問題

1. 右側の「カテゴリを作成」で、例として「基本情報技術者」を作ります。
2. そのカテゴリを選び「問題集を作成」で「テクノロジ」「マネジメント」などを作ります。上位カテゴリは作成・編集時に指定できます。カテゴリの下にさらにカテゴリを置くこともできます。
3. 問題集を開き「問題を追加」から問題文、2〜6個の選択肢、正解、任意の解説・タグを登録します。
4. 登録済みのタグは、次の問題からクリックで付け外しできます。タグは問題集をまたいで再利用できます。
5. 「学習を開始」で、問題集の学習中の問題を出題します。検索・タグで絞る、問題を指定する、出題数を10・20・50・最大500問にする、順序をシャッフルするといった操作もできます。

問題集名・上位カテゴリ・習得ルールは「問題集の設定」、または右側の「⋯」から変更できます。問題の編集画面で別の問題集へ移動できます。誤削除を防ぐため、空の問題集・カテゴリだけ削除できます。

## 累計5回の正解で習得

- 初期設定は **累計5回正解**。途中で間違えても、それまでの正解回数は減りません。
- 各問題に回答回数・正解回数・目標までの進み具合を表示します。提出時に選んだ解答を採点して、自動で記録します。
- 5回正解した問題は「習得済み」に移り、通常の学習から外れます。問題は削除されません。
- 「習得済み」タブで問題を確認・復習できます。「すべて」タブでも、明示的に選んだ問題は習得済みを含めて出題できます。問題を選ばない通常学習では、習得済みを除きます。
- 必要なら問題集ごとに目標を1〜20回に変更したり、「連続正解」方式に変更できます。ルールの変更は既存の記録にも適用されます。
- 問題の編集画面から学習カウントをリセットできます。問題文・画像・選択肢・正解の変更時も、その問題のカウントをリセットします。タグ・解説・保存先だけの変更では維持します。

回答率は「1回以上解答した問題 / 登録問題」、正答率は「正解回数 / 解答回数」、習得率は「習得済み / 登録問題」です。カテゴリ画面では配下の問題集を合算します。未解答のまま提出した問題は、そのテストの採点では不正解になりますが、回答率の回答済みには含めません。学習カウントをリセットした問題や削除した問題は、現在の集計にも反映します。過去の受験履歴は保持します。

## テストの画面

受験画面は資格試験のように問題文と選択肢を中心に配置しています。前後の問題への移動、見直しマーク、解答変更が可能です。時間制限はありません。提出後に正解と解説を確認し、間違えた問題だけ再受験できます。単一正解の選択問題に対応しています。

受験途中の解答は提出まで保存されません。問題の登録・編集は保存ボタンを押した時点で保存されます。

## 旧版からの更新とバックアップ

1. 旧版 QuizeLab を完全に終了します。
2. 念のため `%APPDATA%\QuizeLab` フォルダー全体を別の場所にコピーします。
3. 新版の `.exe` を起動します。同じ保存フォルダーを使うので、データを引き継ぎます。

旧版のカテゴリは問題集として自動移行し、保存済みの受験履歴から回答回数・正解回数を復元します。移行前の SQLite は `quizelab.sqlite.before-v2.bak` に保存します。移行はトランザクション内で実行し、再起動しても同じ履歴を二重加算しません。旧版へ戻す場合は、アプリを終了し、移行前バックアップを別フォルダーへコピーして復元してください。新版の DB を旧版で開いて編集する運用は避けてください。

Windows アプリのデータ保存先は `%APPDATA%\QuizeLab\quizelab.sqlite` です。「ファイル → データ保存フォルダーを開く」から確認できます。本体と保存先を分けているため、`.exe` を入れ替えても記録を保持できます。アンインストール時も学習データは自動削除しません。

バックアップ・復元は **アプリを完全に終了してから** フォルダー全体をコピーしてください。ブラウザ版の保存先は `data/quizelab.sqlite` です。ブラウザ版から移す場合も両方を終了してから SQLite と関連ファイルを保存先へコピーします。既存データの結合機能はないため、コピー先も先にバックアップしてください。

## ソースから開発・ビルド

Node.js 24 以上が必要です。

```sh
npm ci
npm start
```

`npm start` で Electron アプリが開きます。初回は開発用 Electron のダウンロードにインターネット接続が必要です。配布済みの `.exe` はランタイムを同梱しています。

```sh
npm run build:portable
npm run build:win
```

インストール不要版は `dist/QuizeLab-Portable-1.3.0-x64.exe`、NSIS インストーラーは `dist/QuizeLab-Setup-1.3.0-x64.exe` に生成します。Windows 上でのビルドを推奨します。Linux 環境ではインストール不要版の生成を確認していますが、NSIS の生成は Wine の制約により未成功です。

GitHub Actions の「Windows builds」はインストール不要版とインストーラーを独立したジョブでビルドします。一方が失敗しても成功した側の Artifacts を取得できます。配布用の実行ファイルは `downloads/windows-v1.3.0` ブランチ、ソースは `main` で管理します。

従来のブラウザ版を使う場合は `npm run start:web` を実行し、ブラウザで `http://127.0.0.1:3000` を開きます。`npm run dev:web` はサーバー変更を自動反映します。`PORT` と `DB_PATH` でポート・保存先を変更できます。デスクトップ版の内部サーバーは空きポートを選び、`127.0.0.1` だけで待ち受けます。個人利用向けの設計です。

## 検証

```sh
npm test
npx playwright install chromium
npm run test:ui
```

`npm test` は一時 DB で問題管理、階層、タグ、5回習得、画像、永続化、旧 DB の移行に加え、別ユーザーへの問題集共有、学習履歴の非共有、既存データの保護、不正ファイルの拒否を検証します。

`npm run test:ui` はブラウザでカテゴリ・問題集作成、タグの再利用、5回の学習、習得済み除外・復習・リセット、履歴、スマートフォン幅、共有ファイルの保存、ファイル選択・ドラッグによる読み込みとキャンセルを検証します。既存 Chromium を使う場合は `CHROMIUM_PATH` に実行ファイルを指定できます。実際の学習データは変更しません。

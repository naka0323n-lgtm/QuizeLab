# QuizeLab 1.3.1 for Windows

[Windows 64bit 版をダウンロード](https://github.com/naka0323n-lgtm/QuizeLab/raw/refs/heads/downloads/windows-v1.3.1/QuizeLab-Portable-1.3.1-x64.exe)

旧版を完全に終了してから新版の exe を起動してください。既存データを引き継ぎます。Node.js の追加インストールは不要です。

## 今回の変更

受験画面で解答を選び、「正解・解説を見る」を押すと、その問題の正誤・正解の選択肢・解説を確認できます。確認後の解答は固定し、他の問題に移動して戻っても表示を維持します。学習回数は最後に「テストを終了・採点」を押した時に一度だけ記録します。

問題集の階層・累計5回での習得・タグ・画像添付・共有ファイルの保存と読み込みも利用できます。

Windows 実機での操作は未検証です。コード署名はありません。SQLite/API テストとブラウザでの正解・不正解表示テストは実行済みです。

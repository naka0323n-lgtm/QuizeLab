# QuizeLab

自分で選択式問題を作成・管理して、資格試験のような画面で練習できるローカルアプリです。

## 起動

Node.js 24 以上が必要です。外部パッケージやデータベースサーバーの導入は不要です。

```sh
npm start
```

ブラウザで `http://127.0.0.1:3000` を開きます。終了は Ctrl+C。開発時は `npm run dev` でサーバーの変更を自動反映できます。

## 使い方

1. 「問題を作成」でカテゴリ、問題文、2〜6個の選択肢、正解を登録します。解説は任意です。
2. ライブラリで検索・カテゴリ絞り込みを行い、解きたい問題にチェックします。
3. 「テストを開始」で受験します。問題間の移動、見直しマーク、解答の変更が可能です。
4. 提出すると正解・解説が表示されます。間違えた問題だけの再受験もできます。
5. 学習履歴で過去の受験日時と正答率を確認できます。

単一正解の選択問題に対応しています。受験中の解答は提出まで保存されません。問題は登録時点で保存されます。問題の削除後も、過去の採点記録は残ります。

## 保存・バックアップ

問題と採点記録は `data/quizelab.sqlite` に保存されます。外部サービスへの送信はありません。バックアップ・移行時はサーバーを停止してから `data` ディレクトリ全体をコピーしてください。データは Git に含めません。

`PORT` でポート、`DB_PATH` でデータベース保存先を変更できます。例：`PORT=3001 npm start`。サーバーは `127.0.0.1` のみで待ち受けます。個人利用向けで、認証や複数人の同時編集は想定していません。

## 検証

```sh
npm test
```

一時 SQLite データベースを使って問題管理、入力検証、採点、履歴、再起動後の永続化を確認します。実際の学習データは変更しません。

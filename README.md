# QuizeLab

自分で選択問題を作成・管理し、資格試験のような画面で練習できる、Windows 向けローカルアプリです。問題と学習履歴は SQLite に保存し、インターネット接続なしで利用できます。

## Windows で使う

インストール不要版は `QuizeLab-Portable-1.0.0-x64.exe` をダブルクリックするだけで起動できます。データは実行ファイルの隣ではなく、下記のユーザー用保存フォルダーに保存します。

インストーラー版を使う場合：

1. `QuizeLab-Setup-1.0.0-x64.exe` を実行します（Windows 10 / 11、64 ビット）。
2. インストール先を選び、インストールを完了します。
3. デスクトップまたはスタートメニューの「QuizeLab」から起動します。

Node.js やブラウザ、データベースサーバーを別途用意する必要はありません。ウィンドウを閉じるとアプリと内部サーバーが終了します。二重起動すると既存のウィンドウを表示します。

このビルドはコード署名されていません。Windows SmartScreen による確認が表示される場合があります。配布元・ファイルを確認してから実行してください。

## 使い方

1. 「問題を作成」でカテゴリ、問題文、2〜6個の選択肢、正解を登録します。解説は任意です。
2. ライブラリで検索・カテゴリ絞り込みを行い、解きたい問題にチェックします。
3. 「テストを開始」で受験します。問題間の移動、見直しマーク、解答の変更が可能です。
4. 提出すると正解・解説が表示されます。間違えた問題だけの再受験もできます。
5. 学習履歴で過去の受験日時と正答率を確認できます。

単一正解の選択問題に対応しています。受験中の解答は提出まで保存されません。問題は登録時点で保存されます。問題を削除しても過去の採点記録は残ります。

## データの保存とバックアップ

Windows アプリ版の保存先は `%APPDATA%\QuizeLab\quizelab.sqlite` です。「ファイル → データ保存フォルダーを開く」から確認できます。アプリ本体とは別の場所なので、更新・再インストール後も同じデータを利用できます。アンインストール時にも学習データを自動削除しません。

バックアップ時は保存フォルダーを確認し、**アプリを完全に終了してから**フォルダー全体をコピーしてください。復元するときもアプリを終了し、元のフォルダーを別途保管した上でバックアップを戻してください。

従来のブラウザ版で作成したデータを移す場合は、ブラウザ版とデスクトップ版を両方終了し、ブラウザ版の `data` 内の `quizelab.sqlite` と関連ファイル（存在する場合は `-wal`、`-shm`）をデスクトップ版の保存フォルダーへコピーします。既存データの結合機能はないため、コピー先にデータがある場合は必ず先にバックアップしてください。

## ソースコードから起動・ビルド

開発には Node.js 24 以上が必要です。

```sh
npm ci
npm start
```

`npm start` でデスクトップアプリが起動します。SQLite と画面表示のランタイムは Electron に同梱しています。

Windows 用インストーラーの作成：

```sh
npm run build:win
```

生成先は `dist/QuizeLab-Setup-1.0.0-x64.exe` です。Windows 上でのビルドを推奨します。GitHub Actions の「Windows installer」を手動実行しても、Artifacts の `QuizeLab-Windows-x64` から取得できます。Actions のビルドは一般公開の Release を作成しません。

インストール不要版の作成は `npm run build:portable` です。生成先は `dist/QuizeLab-Portable-1.0.0-x64.exe` です。`main` へのプッシュ時にも GitHub Actions で両方の形式を生成します。

従来のブラウザ版を使う場合：

```sh
npm run start:web
```

ブラウザで `http://127.0.0.1:3000` を開きます。終了は Ctrl+C。`npm run dev:web` でサーバー変更を自動反映できます。ブラウザ版の保存先は従来どおり `data/quizelab.sqlite` です。`PORT` と `DB_PATH` でポート・保存先を変更できます。

デスクトップ版の内部サーバーは空きポートを自動選択し、`127.0.0.1` のみで待ち受けます。画面から Node.js の API に直接アクセスできない構成です。個人利用向けで、認証や複数人の同時編集は想定していません。

## テスト

```sh
npm test
```

一時 SQLite データベースを使って問題管理、入力検証、採点、履歴、再起動後の永続化を確認します。実際の学習データは変更しません。Windows でのインストール・起動確認は別途必要です。
